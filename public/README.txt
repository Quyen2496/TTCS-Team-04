GIAO DIỆN NHẬN PHÒNG HOMESTAY

Cấu trúc:
- index.html: giao diện
- style.css: CSS
- script.js: JavaScript xử lý chọn phòng, kiểm tra dữ liệu và nhận phòng

Cách chạy:
1. Giải nén thư mục.
2. Mở file index.html bằng Chrome/Edge.
3. Chọn một phòng đang trống.
4. Nhập thông tin khách.
5. Bấm "Xác nhận nhận phòng".

Đây là frontend demo, chưa kết nối database/backend.
